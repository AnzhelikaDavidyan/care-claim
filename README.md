# CareClaim Ops

A claims and members admin app, built task by task as React + TypeScript interview practice.

## Stack

Vite, React, TypeScript, React Router, Redux Toolkit + RTK Query, TanStack Table,
React Hook Form + Zod, MSW (mock API), Vitest + Testing Library, SheetJS and jsPDF for export.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm test` | Run tests in watch mode |
| `npm run test:run` | Run tests once |
| `npm run typecheck` | Type-check the project |
| `npm run lint` | Lint with oxlint |
| `npm run build` | Production build |

## Folders

```
src/
  app/        store.ts, router.tsx, Layout.tsx (sidebar)
  features/   claims/  members/  export/  toasts/
  shared/     ui/ (Button, Modal, Drawer, StatusChip), hooks/, lib/ (format, csv)
  mocks/      db.ts, handlers.ts, browser.ts
  test/       setup.ts
```

`public/mockServiceWorker.js` is generated by `npx msw init public`.
